**`QiankunShi-Framework`**

中文显示名为：**乾坤昰框架**

## 基本介绍

### 这是什么？

「乾坤昰框架」是一套基于自创本体论的形而上学表达体系，试图用一套统一、自洽、可扩展的概念系统，描述从世界本原到生命、现实、文明乃至寂灭的完整图景。

它的核心主张可以浓缩为三句话：

- 一切的本质是“肄”；
- “肄”通过“氐”呈现与表达；
- 现实是“概念氐”成为“现实氐”后的存在证果。

这个框架不是传统意义上的科学理论，也不是纯粹的文学设定集，而是一套介于哲学思辨、世界观工程、概念设计之间的“源文本”。它提供了一组极为基础且互相绑定的定义，如：**肄、氐、乾坤意昰、创世造物、乾坤寰、六位肄、生命肄、真假虚实肄、轮环肄、炁还肄**等，并以此为砖石，构建出从“零：乾坤”到“柒：主义论”的层层递进结构。

> **注意**：本框架对部分常见词汇进行了再定义或定义扩充，因此阅读时容易出现歧义。为保证自洽性，一切定义均以框架内定义为准。

### 框架结构概览

仓库中现有的源文本共分七大部分：

- **零：乾坤**  
  总纲。定义“肄”与“氐”，提出“肄氐法则”“肄遍历法则”“肄氐造物”，并引出“创世造物”“乾坤意昰”“乾坤寰”“内外乾坤寰”等顶层概念。

- **壹：肄**  
  详述六类最根本的肄：时律、空律、体间、向间、本形、弦形；以及生命肄、真假虚实肄、轮环肄、炁还肄。包含“叠加”“关联”“证存”“引渡”“归还”等交互形式。

- **贰：世界**  
  从“现实”的定义出发，提出“现实差异指数”“世界标准”“世界之内之外”“世界诞生”“世界死亡与完美毁灭”“生死界定世界观”等，用于描述和划分不同世界形态。
  （从此部分开始，之后的所有内容均可作为“示例”，直接解释“肄—氐”体系如何表达为现实常见元素）

- **叁：生命**  
  详细定义生死、寿命、死亡大类、认知与认识、认知权限、心智、本能、族类、诞生、存在、睡眠、梦境等，构成一套完整的生命哲学。

- **肆：寂滞喧汩**  
  讨论终极威胁、非知解题、完美回归、悖谬威胁、寂滞喧汩轮环等，是框架的“末世论”与“循环论”。

- **伍：文明**  
  将生命七因映射为文明七因，提出“世初文明”“文明认知权限”“总文明”等概念，尝试将个体生命哲学扩展为群体文明哲学。

- **陆：学论**  
  定义学科与学说，说明该框架在知识体系中的自我定位。

- **柒：主义论**  
  强调“主义”是由生命出发的诠释体系，是框架对自身视角的最终说明。

每一部分都像是一块独立的积木，但又通过“肄氐法则”紧密咬合。你可以按顺序阅读，也可以从任意一节进入，依靠术语注释回溯全局。

## 用途

### 1. 较强的解释力：应该可以解释许多世界观体系

该框架提供了一套自洽且可扩展的底层元语言，能够以“肄—氐”等概念为公理基础，对许多虚构或现实的世界观体系进行拆解、翻译与再诠释。无论是经典科幻、奇幻、宗教神话、哲学理论还是其他思想实验，只要需要一种可以挂靠的底层结构，都可以尝试与该框架对接。它可以作为不同世界观之间相互比较、通约与映射的“解释框架”。

### 2. 作为开发世界观的原料与工具

对于小说、游戏、剧本、漫画等虚构作品的创作者，本框架可以作为一个“世界观引擎”与“设定原料库”。它提供了：

- 宇宙的诞生方式（喧汩主义/存在主义世界创生）；
- 时空与维度的分类（正体世界、颠向世界、弱标准级等）；
- 生命与死亡的具体规则（轮环引渡、自悖死亡、罪论死亡）；
- 权力/力量的边界（造物权限、上上学说、创世权限许允）；
- 威胁与末日的类型（非知解题、完美回归、世界癌疫）。

### 3. 哲学思辨与本体论探索

该框架提供了一个强系统的本体论模型，适合对“存在”“意识”“现实”“因果”等终极问题感兴趣的读者。它不回避矛盾，而是用“肄遍历法则”“泛化”“存在证果”等机制化解矛盾，形成自洽闭环。你可以把它当作一种现代汉语语境下的形而上学实验，与既有哲学体系进行对比阅读。

### 4. 概念设计与术语体系参考

框架内部创建了大量精确术语，如“命与联”“羁绊肄”“生命意昰”“全画肄”“族类原能”等。这些术语有明确层级、关系和交互规则，可作为构建现实或虚拟体系时的术语模板。即使你不同意其结论，也能从中学习“如何让一套自创概念拥有严谨的派生结构”。

### 5. 作为思想实验进行讨论

本框架本身就是一个大型思想实验：它以自创本体论为起点，通过“肄氐法则”“创世造物”“寂滞喧汩”等机制，推演至生命、文明与终极归宿。你可以把它视为一种可被讨论、质疑与修正的理论模型。

此外，框架中的许多抽象关系也适合进行跨学科类比，例如：

- “肄氐法则”与“概念氐/现实氐”之分，可以类比数学中的抽象定义与物理实现；
- “认知权限”与“存在证果”可以类比信息论中的可观测性；
- “寂滞喧汩”类似热寂与涨落。

## 使用难点

### 1. 新造术语与重新定义的词汇密度极高

框架几乎不使用现成的哲学术语，而是创造了一整套专属词汇，如“肄”“氐”“昰”“意昰”“命与联”“定与肄”“证存”“喧汩”等。同时，它还对部分常见词汇进行了再定义或定义扩充。因此，读者需要先建立一份“术语词典”才能顺畅阅读。仓库本身目前没有附术语索引，所以初次阅读可能频繁回翻。

**建议**：先通读“零：乾坤”与“壹：肄”的首节，理解“肄”“氐”“源定义”“泉定义”这四块基石，再进入后续章节。阅读时遇到任何词汇，请先以框架内定义为准。

### 2. 抽象层级嵌套较深

框架的论述经常是“三层层级”结构：例如“乾坤意昰——天地意昰——肄——氐”；“六位肄——叠与肄——现实氐”；“源定义——泉定义——造物”。这种嵌套容易让读者迷失：当前讨论的是哪一层？是“肄”自身，还是“肄”的呈现，或是“呈现”的证果？

### 3. 循环定义与相互参照

框架中的许多概念是相互定义的，例如：

- “概念氐”被“肄泉定义”直接呈现；
- “现实氐”是“概念氐”的实现；
- 而“概念氐”改变时又会影响“肄”与“现实氐”；
- “现实氐”改变时又会反证“概念氐”。

这种“环状互释”是框架的特点，但也导致无法从单一节点理解全貌，必须整体把握。

### 4. 缺少具体应用示例（持续补充中）

源文本中的“【例】”较少，且多为比喻（如盒子、本子），没有完整展示如何使用该框架解释一个具体的虚构世界或现实现象。读者读完概念后，可能仍不知道“这套东西能拿来做什么”。目前部分设定与示例仍在构思与撰写中，后续会逐步补充。

### 5. 维护与版本演进问题

由于框架体系庞大，任何一处底层定义的修改都可能牵一发而动全身。更新时需要在“保持源定义稳定”和“允许泉定义演化”之间权衡。本框架仍在持续更新中，现有内容可能不是最终形态，后续会持续修订与补充。
